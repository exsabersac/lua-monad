# 异步效果的同步写法（`fx`）

教学层：用 **看起来同步** 的 `Cont.withEnv` 步骤管道书写业务，把 wait / 网络连接 / 点击等 **异步效果** 表达成 `Coro.yield` 请求，由外部解释器兑现；并用 **Stopped / Failed** 表达停止与失败。

| 角色 | 模块 | 职责 |
|------|------|------|
| 业务管道 | `Cont.withEnv` | 按名顺序 `>>`；步骤里调用 `fx.*` |
| 效果原语 | [`src/fx.lua`](../src/fx.lua) | `wait` / `connect` / `click` → yield `{ kind=... }`；`stop` / `fail` → 终态 |
| CPS 挂起 | [`src/coro.lua`](../src/coro.lua) | `Done` \| `Yielded` \| `Stopped` \| `Failed` |
| 解释器 | `fx.run(ma, handlers?, opts?)` | 按 `kind` 分派；支持 `opts.cancel`；返回结构化结果表 |

## 不是什么

- **不是**真实网络或 UI；默认 handlers 只打印日志并返回 mock 表。
- **不是** Lua 原生 `coroutine` / 已放弃的 `perform`/`runDo`。`Coro.yield` 是 Cont 编码的挂起，业务请走 `fx` / `Coro`，不要当原生协程 API。
- `Cont.withEnv` 只组织 `>>`；挂起与恢复仍由 Coro / `fx.run` 完成。
- Cont 层异常请用 `Cont.throw` / `Cont.catch`（见 [`examples/cont_catch_throw.lua`](../examples/cont_catch_throw.lua)）；管道中止优先用 `fx.stop` / `fx.fail`。

## 最小形状

```lua
package.path = "src/?.lua;" .. package.path
local Cont = require("cont")
local fx = require("fx")

local pipe = Cont.withEnv(function(_ENV)
  function step(_)
    return fx.wait(0.05) >> function(_)
      return fx.click("ok")
    end
  end
end)

-- fx.run 始终返回结构化结果表（破坏性变更）
local result = fx.run(pipe(nil))
assert(result.ok)
local value = result.value
```

结果表形状：

| 形状 | 含义 |
|------|------|
| `{ ok=true, value=v }` | 正常 `Done` |
| `{ ok=false, stopped=true, reason= }` | `fx.stop` / 取消 |
| `{ ok=false, failed=true, error= }` | `fx.fail` |

`fx.wait(seconds)` yield `{ kind="wait", seconds }`，resume 后业务得到 `true`。  
`fx.connect(host, opts?)` / `fx.click(target)` resume 值即结果表。

### 停止与取消

```lua
-- 业务主动停止（不调用后续续延）
return fx.stop("user-abort")

-- 取消令牌：每次 Yielded、调用 handler 之前检查
local token = { cancelled = false }
-- … 某处 token.cancelled = true
local r = fx.run(pipe(nil), handlers, { cancel = token })
-- r.stopped and r.reason == "cancelled"

-- 或 cancel = function() return boolean end
```

### 失败与 try

```lua
return fx.fail("disk-full")  -- 或 fx.throw（别名）

local r = fx.try(ma, handlers, {
  on_fail = function(err) return { recovered = true, err = err } end,
  on_stop = function(reason) return nil end, -- nil 保持原 stopped
})
```

自定义 handlers（瞬时、记事件）示例见 [`examples/fx_custom_handlers.lua`](../examples/fx_custom_handlers.lua)。

## 与属性叠用

`__Require__` / `__Trace__` / `__Catch__` 等包装的是 Cont 步骤；步骤体内仍可 `fx.wait`。  
`__Catch__(handler)` 用 `Cont.catch` 包住该步（适合步内 `Cont.throw`）。拒绝时不进入 yield。见 [`examples/fx_with_attrs.lua`](../examples/fx_with_attrs.lua)。

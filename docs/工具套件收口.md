# 工具套件收口（性能基准 + 周边）

版本 **`0.2.16-eng`**。本页把 **bench / 对照 / 分配 / 诊断 / trace / profile / scenarios / CI / mdo** 收口为一份「有什么、怎么用、何时不用」清单。  
命令一页见 [工具速查](工具速查.md)；原理与粗测数字见 [性能与工具](性能与工具.md)；入口细节见 [`tools/README.md`](../tools/README.md)。

**无 Tab DSL**；场景与工具仅拼 Cont / fx 原语。

---

## 清单（inventory）

| 类别 | 路径 | 作用 | 日常 / CI |
|------|------|------|-----------|
| **一键 CI** | `scripts/ci_tools.sh` | `test` → `doctor --ci` → `bench_compare --ci` → `alloc` smoke → `profile` smoke | **CI 默认入口** |
| **单元测试** | `scripts/test_lua53.sh` / `tests/run.lua` | Lua 5.3 回归 | 改代码后先跑 |
| **热路径粗测** | `tools/bench_cont_fx.lua` | Cont/`>>`/map/chain、`fx.seq`、session、lane/proxy/chan/supervise/wait_until/when_all；时间 + ΔKB；`--json` / `--filter` / `--alloc` | 改热路径时本地测 |
| **基线对照** | `tools/bench_compare.lua` | 对照 `bench_baseline.json` 打 Δ%；`--write-baseline` / `--ci`（默认阈值 25%） | 换机或大改后重写基线；CI 回归 |
| **基线数据** | `tools/bench_baseline.json` | 本机 Lua 5.3、默认 **N=20000** 种子（`meta.created` / `host`） | 随仓库提交；勿手改数字 |
| **Markdown 摘要** | `tools/bench_summary.lua` | bench JSON → MD 表（`--out` / `--stdin` / `--from`） | 写性能笔记 / PR |
| **分配热点** | `tools/alloc_hotspot.lua` | Cont `>>`（可选 `--map`）KB before/after + 弱表启发式 | 怀疑分配时；CI smoke N=100 |
| **误配置检查** | `tools/flow_doctor.lua` | 未知 kind、wait 无 scheduler WARN、`STANDARD_KINDS`；`--ci` | 日常 + CI 硬检查 |
| **Trace dump** | `tools/trace_dump.lua` | `opts.trace` → stdout（`--json` / `--lane` / `--chan` / `--wait`） | 交互排查 |
| **Trace 导出** | `tools/trace_export.lua` | 同场景 → JSON 文件（默认 `tools/trace_out.json`，gitignore） | 留档 / 离线分析 |
| **场景打点** | `tools/profile_flow.lua` | wrapping tracer；按 yield kind(+step) top；`--smoke` / `--json` | CI smoke；本地加深 `PROFILE=1` |
| **共享场景** | `tools/scenarios/` | `sync_seq` / `wait_vc` / `lane_pair` / `chan_ping` / `supervise_once`；bench/profile/trace 复用 | 扩展场景时改这里 |
| **@mdo** | `tools/mdo.lua` / `run_mdo.lua` | do 语法预处理与 runner | 仅示例 / 语法实验 |

`opts.trace` **必须是 function**（传 `true` 会被忽略）。

## 推荐工作流

### 日常开发（改 Cont / fx / session）

```bash
# 1) 单元测试
lua5.3 tests/run.lua
# 或
./scripts/test_lua53.sh

# 2) 误配置（未知 kind / 无 scheduler）
lua5.3 tools/flow_doctor.lua

# 3) 相关热路径（按需 filter）
lua5.3 tools/bench_cont_fx.lua --filter 'Cont >>'
lua5.3 tools/bench_cont_fx.lua --filter lane
lua5.3 tools/alloc_hotspot.lua --map
```

排查异步时：

```bash
lua5.3 tools/trace_dump.lua --lane --chan
lua5.3 tools/trace_export.lua --lane --chan --out /tmp/trace.json
lua5.3 tools/profile_flow.lua --filter lane --top 8
```

### 提交前 / 本机 CI

```bash
./scripts/ci_tools.sh
# bench 偶然抖动可 soft-fail：
ALLOW_BENCH_REGRESSION=1 ./scripts/ci_tools.sh
# profile 加深（N=20，默认 smoke N=1）：
PROFILE=1 ./scripts/ci_tools.sh
```

顺序固定：`test_lua53` → `flow_doctor --ci` → `bench_compare --ci` → `alloc_hotspot`（N=100）→ `profile_flow`。

### 换机器 / 大改热路径后刷新基线

```bash
# 默认 N=20000；与 CI / 仓库基线保持一致
lua5.3 tools/bench_compare.lua --write-baseline
lua5.3 tools/bench_compare.lua --ci          # 确认自身对照为 0 回归
git add tools/bench_baseline.json && git commit   # 与说明一并提交
```

可选摘要：

```bash
lua5.3 tools/bench_summary.lua --out tools/bench_summary.md
```

## 游戏时间：什么不要用

| 做法 | 游戏逻辑？ | 说明 |
|------|------------|------|
| **`fx.wait` / `fx.wait_until` + `opts.scheduler`**（VirtualClock / GameSim / Unity scaled） | ✅ **推荐** | 与暂停 / 慢放 / 加速一致 |
| **无 scheduler 的 `busy_wait`** | ❌ 勿用于正式玩法 | 演示 / 单测兼容；`flow_doctor` 会 `[WARN]` |
| **`fx.wait_real`（墙钟）** | ❌ **默认不要** | opt-in：需 `scheduler.schedule_real` 或 `opts.allow_real_time`；否则 **Failed** `{tag=wait_real_unsupported}`。仅网络 / SDK 等少数墙钟场景 |
| **`os.execute("sleep")` / 裸墙钟忙等** | ❌ | 卡住宿主线程，且不进 cancel / abort |
| **工具里的墙钟打点**（`profile_flow` 的 `socket.gettime` / `os.clock`） | 仅测工具 | 测的是本机耗时，**不是**游戏内 scaled time |

工程约定摘要：默认只用**游戏时间**；墙钟 `wait_real` 为明确隔离的 opt-in。详见 [Unity 对接](Unity对接.md) / [工程对接与后续](工程对接与后续.md)。

## 边界（本波已完成 / 有意不做）

**已完成（eng tools wave，至 0.2.16-eng）**

- 可复测 bench + baseline + `--ci` 回归
- alloc / doctor / trace dump·export / profile / scenarios / `ci_tools.sh`
- 中文文档：性能与工具、工具速查、**本收口页**

**有意不做**

- **Tab DSL / tab 树**（保留 Cont/CPS 主线）
- Answer / 代理表对象池（持有 Answer 时复用易脏）
- 把工具数字当严格 microbench SLA（含 GC；基线随机器波动）

若再发现工具 bug，按单点修；本波不再扩面。

# 核心整理说明（0.2.18-eng）

行为保持前提下的调度器拆分与去重说明。公共 API 不变：`require("fx_sched")` / `fx.lua` 表面与原先一致。

## 拆分前痛点

| 文件 | 行数（约） | 问题 |
|------|------------|------|
| `fx_sched.lua` | 2961 | 单文件塞满 nursery / wait / chan / lane·proxy / supervise / session·pump |
| `fx.lua` | 942 | 可接受；少量 stop/abort 别名重复 |
| `cont_env.lua` | 1107 | Cont 热路径，本轮不动 |
| `cont.lua` / `coro.lua` | 334 / 227 | 热路径，本轮不动 |

### 重复与难跟读处（审计）

1. **终态 / join 唤醒**：`try_complete_joins`、`settle_group`、`join` / `join_handles` 即时路径多次手写 `Failed` / `Aborted` / `Stopped` 分支。
2. **timer 回调样板**：`wait` / `wait_real` / `wait_event` / 通用 async handler 共用「flag.cancelled → when_flow_active → resume → `_pump`」骨架。
3. **supervise 清理**：`settle_group` 四个失败分支各调一次 `clear_supervise_backoff` + 清 `waiting_group`。
4. **前向声明网**：`drive_until_block` ↔ `on_task_terminal` ↔ `settle_group` ↔ `cancel_descendants` ↔ supervise 互相引用，单文件靠 `local x` 前向声明，拆文件后改用共享袋 `S` 晚绑定。
5. **`drive_until_block` ≈ 980 行**：按 `req.kind` 巨型 if/elseif，是最大可读性瓶颈。

## 本轮模块图

```
fx_sched.lua              薄编排：建 S、依次 install、导出公共 API
├── fx_sched_util.lua     追踪 / 墙钟 / busy_wait / cancel 检测 / Answer 标签 /
│                         when_flow_active / normalize_opts / 终态 result 辅助
├── fx_sched_chan.lua     有界 channel：detach / settle / close / admit
├── fx_sched_nursery.lua  nursery·task、deadline、cancel/stop、lane/proxy 宿主机、
│                         settle_group / on_task_terminal / try_complete_joins、
│                         start_group / start_timeout_race
├── fx_sched_supervise.lua supervise 启停 / backoff / 重启判定
├── fx_sched_drive.lua    drive_until_block + 共享 timer/join 辅助；按 kind 分派
└── fx_sched_session.lua  start_session / run_session / run_parallel（含 pump）
```

`require("fx_sched")` 仍返回同一表面：`set_tracer` / `get_tracer` / `start_session` /
`run_session` / `run_parallel` / `busy_wait` / `now` / `_emit_trace`。

## 已做去重

- `arm_scheduler_timer`：scheduler 路径下 wait / wait_real 共用登记与回调。
- `resume_task_and_pump`：`when_flow_active` + resume/fail + `_pump`。
- `apply_finished_child_to_joiner`：join 方对已结束子任务的 Done/Failed/Aborted/Stopped。
- `settle_group` 内 supervise 清理收成局部一步。

## 有意保留的债务（后续）

1. `drive_until_block` 仍偏长：可再拆 `fx_sched_wait.lua` / `fx_sched_lane.lua`（yield handler 表），本轮为降风险先留在 drive。
2. `fx_sched_nursery.lua` 仍集中 terminal+join+cancel；与 drive/session 循环依赖靠 `S` 晚绑定，可读性好于单文件但仍需脑内跟引用。
3. `cont_env.lua` 体量大，属 Cont 环境组合，与调度正交，单独波次再整理。
4. `fx.lua` 仅轻量收口别名（lane_stop/abort、proxy_stop/abort），未做大搬迁。

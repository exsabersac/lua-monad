# 设计说明

本文简要说明本库的架构取舍，便于对照源码阅读。实现细节以 `src/` 为准。

**Cont / CPS 协程的详细原理**（续延传递、callCC、shift/reset、yield 轨迹）见 [CPS设计与原理.md](./CPS设计与原理.md)。

## 1. 总览

目标：在 **纯 Lua** 里复现 Monad 的最小接口与若干经典实例，并额外用 **Cont** 做一层 CPS 协程，方便理解「续延 = 剩余计算」。

分层可以记成：

```
应用 / 示例（demo、walk_the_line、cont_*、coro_*）
        ↑
具体 monad（Maybe / List / State / Status / Identity / Reader / Writer / RWS / Cont）+ Coro API
        ↑
monad.makeMonad（unit/bind 包装、wrap/unwrap、元表糖）
```

`makeMonad` 不关心业务语义，只统一「出口形态」和运算符；各模块提供 `raw` 的 `unit`/`bind`。

## 2. `makeMonad` 与 `wrap` / `unwrap`

### 为什么要 wrap？

Lua 的运算符元方法挂在**值**的元表上，而不是挂在模块表上。因此 `unit`/`bind` 的返回值必须带上共享元表 `mt`，`ma >> f` 才能工作。

### 两种值形态

| 形态 | 代表 | wrap 行为 |
|------|------|-----------|
| 表形 | Maybe、List、Status、Identity、Writer | `setmetatable(表, mt)`，字段（`tag`、`log`、数组等）仍直接可读 |
| 函数形 | Cont、State、Reader、RWS | 包成 `{ _fn = f }`，`mt.__call` 转发；对外仍可 `ma(k)` / `ma(s)` / `ma(env)` |

`unwrap` 只对「本实例 `mt` 且带 `_fn`」的代理拆封；表形与裸表/裸函数原样穿过。这样：

- 用户写的 `f` 可以返回已 wrap 的值，也可以返回裸表/裸函数；
- `raw_bind` 始终看到裸数据，实现简单；
- 对外 API 出口再次 `wrap`，形态一致。

### 符号糖对应关系

| Lua | 实现 | Haskell |
|-----|------|---------|
| `ma >> f` | `bind(ma, f)` | `>>=` |
| `ma .. mb` | `bind(ma, λ_. mb)` | `>>`（丢弃左结果） |
| `M(x)` | `M.unit(x)` | `return` / `pure` 的模块糖 |

注意：Lua 中 `..` 与 `>>` 的优先级与 Haskell 不同，混用时请加括号（见走钢丝示例里的 `peel`）。

## 3. Cont 层：mapCont / withCont / callCC / 定界续延

Cont 除 `unit` / `bind` / `runCont` / `callCC` 外，还提供：

| API | 语义要点 |
|-----|----------|
| `evalCont` | 恒等续延取答案 |
| `mapCont f m` | `Cont (f ∘ c)`：改造**答案** `r` |
| `withCont f m` | `Cont (c ∘ f)`：改造**续延**再交给 `c` |
| `reset` / `shift` | 教学用定界续延；`reset ≡ evalCont`；`shift` 把定界 `k` 交给 `f` |

`callCC` 的 `escape(a)` 是「非定界」逃逸：直接交给进入 callCC 时的外层续延，后面的计算不再贡献答案（abort 风格）。`shift`/`reset` 则只截取 reset 提示内的续延，可多次调用捕获到的 `k`（见测试中的 `3*2+4*2=14`）。

## 4. Cont 协程的三层

`coro.lua` 不是 Lua `coroutine`，而是 Cont 上的编码：

1. **Cont 层** — `Cont r a = (a → r) → r`，提供 `unit` / `bind` / `runCont` / `callCC` / `mapCont` / `withCont` / `shift` / `reset` 等。
2. **答案类型层** — 把 Cont 的结果类型 `r` 固定为：
   - `Done { tag="done", value }`
   - `Yielded { tag="yielded", value, cont }`
   - `Stopped { tag="stopped", reason? }` / `Failed { tag="failed", error }`
   其中 `cont` 是「恢复时收到的值 → Answer」的续延。
3. **Coro API 层** — `yield` / `start` / `resume`，以及驱动助手：
   - `yield(v)`：不调用当前 `k`，而是 `return Yielded(v, k)`，从而**捕获**续延；
   - `stop` / `fail`：同样不调用 `k`，直接返回终态 Answer；
   - `start(ma)`：用 `λa. Done(a)` 作顶层续延；
   - `resume(y, b)`：`y.cont(b)`；
   - `step`：Done/Stopped/Failed 透传 / Yielded 则 resume；
   - `run(ma, handler)`：循环调用 handler 取得 resume 输入；
   - `collect(ma)`：记录 yield 载荷，resume 用 `true`。

因此「挂起」只是普通函数返回，没有调度器；教学上对应「yield = 捕获当前续延」。

## 5. 单子定律测试方式

`tests/run.lua` 对每个实例调用 `test_laws(name, M, samples, f, g, run)`：

- **左单位**：`unit(a) >>= f` ≡ `f(a)`
- **右单位**：`m >>= unit` ≡ `m`
- **结合律**：`(m >>= f) >>= g` ≡ `m >>= (λx. f(x) >>= g)`

`run` 缺省为恒等。对 Cont / State / Reader / RWS / Writer / Identity，先跑成普通值再比较（例如 Cont 用恒等续延，State 用固定初态抽成 `{ a, s }`，Reader 固定 env，Writer 比较 `{ value, log }`）。相等性用浅结构 `eq`（忽略元表；函数代理比 `_fn` 引用）。

此外还测短路（Nothing / Err）、展平（List）、`>>` / `..` / 模块调用糖，以及 Cont 的 `evalCont`/`mapCont`/`withCont`/`callCC`/`shift`/`reset` 与 Coro 的 `step`/`run`/`collect`。

## 6. LYAH Walk the line 映射

《Learn You a Haskell》「A Fistful of Monads」中 Pierre 走钢丝：

| Haskell | 本库 |
|---------|------|
| `type Pole = (Birds, Birds)` | `{ left, right }` 二元数组 |
| `landLeft n :: Pole -> Maybe Pole` | 柯里化 `landLeft(n)(pole)` |
| `>>=` | `>>`（`__shr`） |
| `>>`（丢弃） | `..`（`__concat`） |
| `return (0,0)` | `Maybe.Just({0,0})` 或 `Maybe({0,0})` |
| 失衡 / `banana` | `Maybe.Nothing()` |

示例脚本：`examples/walk_the_line.lua`（含与书中一致的成功链、失衡链、banana、以及用 `.. Nothing` 插入失败）。

## 7. 新单子选用指南

| 单子 | 何时用 |
|------|--------|
| **Identity** | 需要统一 monadic 接口、但无额外效应；教学对照 |
| **Reader** | 只读配置 / 依赖注入；不想显式传 env 参数 |
| **Writer** | 累积日志、审计轨迹；默认 string，或 `WriterList` / 自定义 monoid |
| **RWS** | 同时需要读环境、写日志、改状态的教学组合 |
| **Status** | 可失败且要错误信息（≈ Either / Result）；**不另建 Either** |
| **State** | 隐式可变状态线程 |
| **Maybe / List / Cont** | 可失败无载荷 / 非确定 / 续延与 CPS |

## 8. 非目标

- 不实现完整 typeclass / 高阶 kind；
- 不做多路调度或与 `coroutine` 互操作；
- 不追求与 Haskell 库 API 一一同名，只求语义可对读。

## Cont.withEnv 环境组合

`src/cont_env.lua` 提供 Cont 专用的步骤环境：`withEnv(body)` 在 env 上收集函数并默认折成 `unit(x) >> …`。不依赖 PLoop / 原生协程。说明见 [Cont环境组合.md](./Cont环境组合.md)。

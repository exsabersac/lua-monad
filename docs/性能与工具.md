# 性能与工具

目标宿主：**Unity + Lua 5.3**。热路径粗测与周边工具说明（版本 **`0.2.4-eng`**）。

## 瓶颈（测什么）

`tools/bench_cont_fx.lua` 与实现注记：压力主要来自

1. **每步 Cont 代理表**（`setmetatable({ _fn = … }, mt)`）
2. **`>>` / `bind` 闭包**（构造时一层、求值时再包续延）
3. **`Cont.unit` 再包一层**（`ma >> function(x) return Cont.unit(f(x)) end` 时尤其明显）
4. session / `fx.run` 调度（`fx.seq×3 run` 远慢于纯 `evalCont`，属预期）

**未做**（风险高）：Answer（Done/Yielded）对象池——调用方可能持有 Answer，复用易脏读。优先安全路径。

## 0.2.4-eng 已做优化

| 改动 | 效果 |
|------|------|
| **Cont.bind** 专用实现 | 去掉 makeMonad 的 bind-time adapter；`f` 返回已 wrap 的 Cont 时直接调 `_fn(k)` |
| **Cont.chain(ma, mb)** | ≡ `ma >> (_ → mb)` / `ma .. mb`，无用户闭包 |
| **Cont ..** | 走 `chain` |
| **Cont.map / then_ / fmap** | 直接改续延，避免 `bind+unit` 双代理 |
| **fx.seq** | 用 `Cont.chain` 串联 |

## 粗测数字（本机 box，Lua 5.3.6，N=20000）

非严格 microbench（含 GC）；取三次运行的大致中位。

### 优化前（`07c9b47`，仅旧四项）

| 项 | 时间 | 吞吐 |
|----|------|------|
| Cont >> chain | ~0.029 s | ~6.9×10⁵ /s |
| Coro.start unit | ~0.016 s | ~1.3×10⁶ /s |
| fx.seq×3 run | ~3.23 s | ~6.2×10³ /s |
| session wait(0) N=5000 | ~0.084 s | ~6.0×10⁴ /s |

### 优化后（`0.2.4-eng`）

| 项 | 时间 | 吞吐 | ΔKB（约） |
|----|------|------|-----------|
| Cont >> chain | ~0.023–0.028 s | ~7.2–8.8×10⁵ /s | ~7814 |
| Cont.map chain | ~0.010–0.012 s | ~1.7–2.0×10⁶ /s | ~3880 |
| Cont.chain / .. | ~0.019–0.021 s | ~9.5–10.8×10⁵ /s | ~5157 |
| Coro.start unit | ~0.015 s | ~1.3×10⁶ /s | 波动 |
| fx.seq×3 eval | ~0.050–0.053 s | ~3.8–4.0×10⁵ /s | ~136 |
| fx.seq×3 run | ~3.2 s | ~6.2×10³ /s | session 主导 |
| session wait(0) N=5000 | ~0.080–0.083 s | ~6.0×10⁴ /s | — |

**解读**

- **`>>` 热路径**：约 **+15–25%** 吞吐（同 N 下时间下降）。
- **纯映射**：优先 `Cont.map` / `then_`（约 **2×** 于 `>> unit`，ΔKB 近半）。
- **丢弃左值 / seq**：用 `Cont.chain` 或 `..` / `fx.seq`（比手写 `>> function(_) return next end` 更轻）。
- **`fx.run(seq)`**：时间几乎全在 session；要量 seq 本身请看 **fx.seq×3 eval**。

复现：

```bash
lua5.3 tools/bench_cont_fx.lua 20000
```

## 工程建议

1. 能 `map` 就不要 `>> unit`。
2. 顺序丢弃用 `Cont.chain` / `..` / `fx.seq`，勿每步新建 `function(_) return next end`。
3. 复用 **session / flow**，缩短管道；避免无谓 `>>`。
4. Trace 默认关；排查时用 `tools/trace_dump.lua` 或 `opts.trace = fn`。

## 工具入口

见 [`tools/README.md`](../tools/README.md)：

## 后续可选（未做）

| 想法 | 风险 / 备注 |
|------|-------------|
| Done/Yielded 小表池 | 持有 Answer 时复用会脏；需显式 `release` 或世代号 |
| seq 构造期单 wrap 折成裸 CPS | 可再减代理，但要保证与 `>>` 语义/元表一致 |
| fx.run 轻量同步快路径（无 yield 时跳过 session） | 可大幅拉低 `fx.seq×3 run`；需仔细对齐 cancel/trace |
| 代理表 freelist | 与 Answer 池类似，跨持有不安全 |
